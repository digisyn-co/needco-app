# Need.co — Customer App

"Services at your doorstep" — the customer-facing web app for Need.co, an on-demand local services marketplace serving Iloilo City. Customers sign in with Google or Facebook to request home/errand services from local providers. Part of a 4-app suite (customer, worker, admin, and this landing/auth shell). Built with Vite.

Live: https://needco-app.vercel.app
